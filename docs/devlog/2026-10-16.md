## Decisions - Categories와 독립적인 Attributes 분류

- Attributes는 도안 종류와 별개인 선택적 배열이다. 기존 메타데이터 버전 1과 v1/v2 검토 복구본에서 필드가 없어도 정상적으로 읽으며 기존 기록을 일괄 수정하지 않는다.
- 특성을 파일명·디자이너·PDF에서 추정하지 않는다. 기존 파일은 미지정으로 시작하고 J님이 직접 선택한다.
- 한 분류 축을 저장할 때 다른 축·도안 ID·경로·대표 페이지·분석 기록은 유지한다. Attributes만 바꾸는 작업으로 기존 categorySource도 변경하지 않는다.
- 비우기는 별도 Clear attributes 동작으로 제공해 체크 누락과 전체 삭제를 구분한다.

## Work Summary - Pattern Library 썸네일 밀도와 클릭 역할 개선

J님이 갤러리 여백·중복 파일명·대표 페이지 안내 때문에 썸네일 공간이 부족하고 카드 전체 클릭이 편집으로 연결되는 문제를 설명했다. 세로 PDF 중심의 갤러리를 만들고 제목·디자이너·편집 버튼에 각각 하나의 동작을 연결하는 추천안을 승인해 반영했다.

## Work Completed - Pattern Library 썸네일 밀도와 클릭 역할 개선

- Pattern Library를 열면 화면 너비를 활용하고, 카드 최소 너비·내부 여백·간격을 조정했다. 2048 CSS px에서 7열, 1280px에서 4열로 표시하며 글자 크기는 유지한다. Organize Files의 기존 너비는 유지한다.
- 썸네일을 A4에 가까운 세로 비율로 고정하고 이미지를 채워 표시한다. 비율이 다른 PDF는 가운데를 기준으로 일부 잘리며 원본 PDF는 변경하지 않는다.
- 카드 전체의 details/summary 펼침을 article과 별도 Edit 버튼으로 교체했다. 썸네일 우측 하단에 항상 Edit를 표시하며 편집 중에는 Close로 바뀐다. 키보드 작동과 펼침 상태 안내를 제공한다.
- 파일 제목은 기존 Open PDF 기능에 연결해 새 브라우저 탭에서 연다. 디자이너 이름은 앱 내부의 해당 디자이너 필터에 연결한다. 다른 검색 조건을 유지하고 첫 페이지로 이동하며 기존 대량 선택을 해제한다. Singles도 동일하게 동작한다.
- 파일 경로와 Cover page 안내는 카드 기본 표시에서 숨기고 편집 영역에서만 제공한다. Categories·Attributes·대표 페이지 편집 및 미저장 값의 검색·페이지 이동 후 복원과 저장 실패 보호는 유지한다.
- 앱 자산 쿼리를 갱신하고 기존 카드 편집 테스트를 새 Edit 진입 방식에 맞게 수정했다. 임시 OPFS에 긴 파일명과 실제 가로 PDF를 추가해 렌더링을 확인했다.

## Decisions - Pattern Library 썸네일 밀도와 클릭 역할 개선

- 제목은 PDF 열기, 디자이너는 앱 필터, Edit는 수정으로 역할을 분리한다. Windows 탐색기 연동은 추가하지 않는다.
- 중복 경로·페이지 안내를 삭제하거나 메타데이터를 변경하지 않고 필요한 편집 화면에 남겼다. 썸네일 이미지를 다시 생성할 필요 없이 CSS로 비율과 잘림을 조정한다.
- 제목 16px·디자이너 15px·분류와 Edit 14px를 유지하고 긴 이름은 줄바꿈한다. 텍스트 버튼은 불필요한 기본 버튼 높이를 줄이면서 최소 24px 클릭 높이를 확보했다.
