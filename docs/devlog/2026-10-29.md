# 2026-10-29 PDF Organizer Development Log

## Work Summary

J님이 `Remember alias`로 디자이너를 연결하면 화면이 아래로 크게 이동한다고 보고했다. 저장 후 검토 카드 전체를 재생성하는 경로를 찾아, 기존 카드를 유지하며 연결 정보만 갱신하도록 수정했다.

## Work Completed

- Chrome 임시 샘플 200개(현재 배치 100개)로 재현했다. 저장 직후 누른 버튼과 카드가 DOM에서 제거되고 포커스가 `BODY`로 이동했다. 한 재현에서는 스크롤 좌표가 같아도 작업 카드가 화면상 약 518px 위로 밀렸다.
- `rememberConnection`의 전체 `renderSortingRows` 호출을 제거했다. 저장한 카드와 새 별칭으로 자동 연결된 카드만 필드·연결 표시·버튼 상태를 갱신한다.
- 자동 연결로 파일명이 바뀐 경우 해당 카드의 자동 분류도 기존 규칙으로 갱신한다. 다른 카드, 수동 분류, 파일명 편집란의 펼침 상태, PDF 표지는 유지한다.
- 변경된 JavaScript 두 파일의 정적 자산 버전을 갱신하고 `tests/aliases.browser.cjs` 회귀 테스트를 추가했다.

## Decisions

- 포커스를 강제로 되돌리거나 스크롤을 사후 복원하지 않고 원인이 되는 카드 재생성을 없앴다. `content-visibility`와 `contain-intrinsic-size`를 사용하는 카드의 측정 높이가 재생성 시 사라지는 문제도 함께 피한다.
- 별칭 저장·백업·기존 매핑 처리와 빈 파일 자동 연결 조건은 유지한다. 자동 연결 함수가 변경된 파일 목록을 반환하게 하여 갱신 범위를 한정했다.
- 검증은 실제 사용자 폴더 대신 격리된 Chrome 프로필과 임시 OPFS 샘플로 수행했다.

## Current Status

- Chrome 100% 줌, 2048×1152 및 1280×1152에서 첫 번째·21번째·100번째 카드의 마우스 클릭과 Enter 실행을 검증했다. 여섯 경우 모두 스크롤 및 카드 위치 변화가 0px이고 버튼 포커스를 유지했다.
