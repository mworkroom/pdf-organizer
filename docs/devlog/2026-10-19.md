# 2026-10-19 PDF Organizer Development Log

## Work Summary

J님이 Organize Files에서 Categories와 Attributes를 각각 최소 하나 선택해야 다음 작업을 진행하도록 요청했다. 기존 파일명·디자이너 필수 검사에 두 분류 조건을 추가하여 중복 검사와 정리를 모두 차단하고, 누락된 카드와 선택 영역을 안내하도록 했다.

## Work Completed

- 현재 묶음에서 제외하지 않은 파일마다 등록된 Category와 Attribute가 각각 하나 이상 있는지 검사한다. Check duplicates와 Organize batch의 기존 공통 검사에서 확인하므로 중복 검사 후 선택을 해제해도 정리 전에 다시 차단한다.
- 카드 상태에 누락 항목을 표시하고, 진행 버튼을 누르면 해당 카드·선택 영역을 강조한다. 각 영역에 14px 오류 문구와 aria-invalid·설명 연결을 추가하고 첫 누락 항목에 포커스를 이동한다. 선택을 보완하면 강조와 완료 안내를 갱신한다.
- 정리 카드에서는 Categories를 모두 해제할 수 있게 했다. 수동으로 비운 상태는 재렌더링·자동 저장·Resume review에서도 유지하여 Unknown으로 자동 대체되지 않게 했다. 정리 실행은 필수 검사로 막는다.
- 기존 자동 분류와 Unknown은 선택된 Category로 인정한다. Attributes를 임의로 채우지 않으며, 여러 항목 선택도 허용한다. 제외 파일과 대기·보류 파일은 현재 묶음 필수 검사에서 제외한다.
- 묶음 안내와 카드에 필수 선택 조건을 명시하고 자산 쿼리를 갱신했다. 기존 정리 검증은 샘플에 명시적으로 Attributes를 지정하도록 조정하고 전용 Chrome 통합 검증을 추가했다.

## Decisions

- 필수 조건은 Organize Files의 처리 단계에 적용한다. 보류·화면 전환·자동 저장은 미완성 상태에서도 가능하며, Pattern Library의 기존 미지정 도안과 Attributes 비우기·None 필터 계약은 유지한다.
- 진행 버튼을 숨기거나 무조건 비활성화하는 대신, 누르면 필요한 항목과 해당 파일을 알려 수정할 수 있도록 기존 검증 흐름을 확장했다.
- 라이브러리에 저장하는 Categories 비어 있지 않음 규칙은 유지한다. 검토 중인 빈 선택만 임시 편집 상태로 보존하며, 조건 충족 전에는 정리하지 않는다.
