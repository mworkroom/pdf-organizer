# 2026-10-24 PDF Organizer Development Log

## Work Summary

디자이너 폴더가 약 450개여서 자주 찾는 디자이너의 도안만 모아 보기 어렵다는 J님의 요청으로, 디자이너 즐겨찾기와 Favorites 필터를 추가했다. 갤러리와 Designer folders 목록에서 같은 즐겨찾기를 사용하며 기존 검색·분류 흐름에 결합했다.

## Work Completed

- 도안 카드와 디자이너 폴더 이름 옆에 ☆/★ 등록·해제 버튼을 추가했다. 키보드 조작, 접근성 이름, 눌림 상태를 지원한다. 폴더 이름을 누르면 갤러리에서 해당 디자이너로 필터링하고 갤러리 위치로 이동한다.
- 갤러리와 폴더 목록에 각각 All designers/Favorites 전환을 추가했다. 갤러리에서는 즐겨찾는 디자이너들의 도안을 함께 표시하며 검색·Category·Attributes·개별 Designer 조건을 교집합으로 적용한다. Favorites 상태에서는 Designer 선택지도 즐겨찾는 디자이너로 좁힌다.
- `!pdf-organizer-library.json`에 선택적 `favoriteDesigners` 배열을 추가했다. 기존 JSON에 필드가 없어도 정상적으로 열며, 재스캔·재연결·브라우저 재시작 후 등록 내역을 유지하고 다른 라이브러리와 구분한다. 기존 백업·디스크 충돌 검사를 재사용했다.
- `!zz_Singles` 도안의 디자이너도 카드에서 즐겨찾기로 등록할 수 있다. 디자이너 폴더 목록은 실제 폴더 목록이라는 기존 범위를 유지한다.
- 필터나 즐겨찾기 변경으로 결과 범위가 달라지면 일괄 선택과 페이지를 초기화한다. 저장 실패 시 등록 상태를 바꾸지 않고 두 화면에 오류를 안내하며, 아직 저장하지 않은 도안 편집을 보존한다. Clear filters는 갤러리 Favorites 조건도 해제한다.
- 주요 전환 버튼은 15px, 디자이너 이름은 15~16px, 별 아이콘은 24px로 구성하고 긴 이름이 줄바꿈되게 했다. 정적 자산 버전 쿼리도 갱신했다.

## Decisions

- 즐겨찾기는 개별 PDF가 아니라 디자이너 이름에 연결한다. 일반 폴더는 최상위 폴더명, Singles 등은 기존 갤러리의 디자이너 판별 결과를 그대로 사용하여 기존 데이터 의미를 유지한다.
- 즐겨찾기 등록 내역은 라이브러리 JSON에 저장하고 화면별 Favorites 전환 상태는 세션 내에서만 유지한다. 갤러리와 폴더 목록의 범위 전환은 독립적으로 사용하되 별 표시와 등록 내역은 공유한다.
- 폴더가 일시적으로 사라지거나 비어 있어도 등록 내역은 자동 삭제하지 않는다. 이름 변경을 추측하여 즐겨찾기를 이전하지 않는다.

## Current Status

- 전체 Node 테스트 54개, JavaScript 문법 검사, `git diff --check`가 통과했다. 기존 JSON 호환, 배열 검증, 재스캔 보존, 복합 필터를 단위 테스트에 추가했다.
- 격리된 Chrome의 임시 OPFS에 디자이너 폴더 450개와 갤러리 샘플 131개를 만들어 전용 통합 검증을 통과했다. 별 키보드 조작·두 화면 동기화·복합 필터·Singles·미저장 편집 보존·선택 초기화·쓰기 실패·외부 JSON 충돌·재시작 후 유지·다른 라이브러리와의 분리를 확인했다.
- 기존 Chrome 갤러리·카탈로그·필수 분류 통합 검증도 통과했다. 예상한 카탈로그 실패 주입 1건 외 예기치 않은 콘솔 오류는 없었다.
- Chrome 100% 줌의 2048·1280px에서 갤러리와 폴더 목록 스크린샷을 검토하고 가로 넘침·이름 잘림·버튼 접근을 확인했다.
- Browser/Chrome 플러그인은 설정에 활성화되어 있지만 현재 세션에는 Browser 스킬·제어 도구가 노출되지 않아 기존 Playwright와 설치된 Chrome을 사용했다. 초기 로컬 서버 접근은 실행 환경의 네트워크 제한으로 실패하여 서버와 Chrome 검증을 같은 허용된 실행 환경에서 재실행했다. 새 통합 테스트의 샘플 준비 대기와 준비 후 화면 복귀도 보완했다.
- 로컬 코드 수정 완료 상태이다. 실제 사용자 폴더와 검토 저장본은 변경하지 않았으며 커밋·푸시·배포는 수행하지 않았다.

## Work Completed - 디자이너 드롭다운을 실제 폴더 기준으로 제한

- 드롭다운이 기존 `designerFolders` 목록을 그대로 사용하도록 수정했다. `!zz_Singles` 파일명과 루트·특수 폴더의 저장된 디자이너명은 선택지에 추가하지 않는다. Favorites도 이 폴더 목록 안에서 등록된 이름만 표시한다.
- 실제 폴더가 있으면 현재 PDF 수와 관계없이 선택지에 포함한다. 폴더 생성 시의 3개 기준을 다시 계산하지 않으며, 별칭을 통해 이름을 추가하거나 합치지 않는다.
- 실제 폴더가 없는 카드의 디자이너명은 일반 텍스트로 표시하여, 클릭해도 드롭다운에 없는 값으로 필터가 설정되는 문제를 방지했다. 카드의 디자이너명 표시와 즐겨찾기 등록, 전체 검색은 유지한다.
- Refresh library에서 실제 폴더 목록도 다시 읽도록 수정했다. 외부에서 추가·삭제한 폴더가 새로고침 후 메뉴에 반영되며, 없어진 선택지는 초기화된다. 정적 자산 버전도 갱신했다.
